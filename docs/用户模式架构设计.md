# 用户模式架构设计

## 核心问题

当前前端所有界面试图同时满足两类用户，导致两类用户都不满意：

| 用户 | 核心诉求 | 被什么干扰 |
|------|---------|-----------|
| **采购业务用户**（95%） | 快速判断异常、走审批流程、导出报告 | 技术术语、调试按钮、H编码、播放控制 |
| **AI运维用户**（5%） | 调试模型、Override参数、查看推理链 | 业务约束遮挡、缺少技术细节 |

## 解决方案：用户模式切换

```
┌─────────────────────────────────────────────┐
│  [采购模式 ●]  [调试模式 ○]     ← 顶部切换  │
├─────────────────────────────────────────────┤
│                                             │
│  同一套数据，两套渲染                        │
│                                             │
│  采购模式:                                   │
│  - 只展示业务必要信息                         │
│  - 所有操作符合内控流程                       │
│  - 无技术术语、无调试功能                     │
│  - 一键导出报告                              │
│                                             │
│  调试模式:                                   │
│  - 完整技术细节 (DAG/H编码/工具名)           │
│  - 所有调试功能 (Override/What-If/反馈)      │
│  - 播放控制、倍速回放                        │
│  - 推理链全量展示                            │
└─────────────────────────────────────────────┘
```

## 架构实现

### 1. UserModeContext

```tsx
// context/UserModeContext.tsx
type UserMode = 'procurement' | 'debug'

const UserModeContext = createContext<{
  mode: UserMode
  toggleMode: () => void
}>({ mode: 'procurement', toggleMode: () => {} })
```

### 2. Layout 顶部切换

```
┌──────────────────────────────────────────────────┐
│  Logo     工作台  异常列表          采购模式│调试  │
│                                    ●──────○     │
└──────────────────────────────────────────────────┘
```

### 3. 页面按模式渲染

```
QuoteDetail (采购模式)            QuoteDetail (调试模式)
─────────────────────            ─────────────────────
偏高/偏低 → 决策 → 导出           DAG预览 → 证据Tab → Override
                                 → What-If → 推理链

ExecutionTrace (仅调试模式可见)     ExecutionTrace (调试模式)
─────────────────────             ─────────────────────
「报价异常溯源」                   「Agent推理链工作台」
结论摘要 → 证据明细 → 导出         时间线/DAG → 播放控制
                                   → H假设 → 注入反馈 → Override
```

### 4. 侧边栏按模式变化

```
采购模式侧边栏:                   调试模式侧边栏:
  工作台                           工作台
  异常列表                         异常列表
  统计分析                         统计分析
  [新建分析]                       [新建分析]
                                   ─────────
                                   调试入口 (仅调试模式显示)
                                   Demo中心
                                   推理链
```
